# Feature: ลงทะเบียนเข้าชมงาน (Event Registration)
Spec ID: SPEC-REG-001 | Source: Use Case Specification UC-04 | Use case: UC-04
Owner: TBD | Status: Draft v2 | Updated: 2569-09-20

## Goal
นักศึกษา / ผู้ชม ที่เข้าสู่ระบบแล้วลงทะเบียนเข้าร่วมอีเว้นต์ที่เปิดให้ลงทะเบียน และถูกบันทึกเป็นผู้ลงทะเบียน
โดยผู้จัดงานทราบจำนวนผู้เข้าร่วมและจำนวนไม่เกินที่นั่งของงาน

## Scope
### In scope
- ตรวจสอบจำนวนที่ว่างของอีเว้นต์ที่เลือก และแจ้งจำนวนที่เหลือเมื่อเหลือน้อย
- บันทึกการลงทะเบียน และแสดงผลการลงทะเบียน
- ป้องกันการลงทะเบียนซ้ำ และไม่ให้ลงทะเบียนเมื่อเต็มจำนวน
### Out of scope
- ยกเลิกการลงทะเบียน (UC-05) | ตรวจสอบรายชื่อผู้เข้าร่วม (UC-13) | สร้าง / แก้ไขอีเว้นต์ (UC-10)
- เข้าสู่ระบบ (UC-01) - ถือว่าทำสำเร็จแล้วก่อนเข้าฟีเจอร์นี้ (precondition)
- การลงทะเบียนแข่งขันดนตรี ซึ่งแยกจากการลงทะเบียนเข้าชม

## Constraints
- PRE-REG-01 ผู้ใช้เข้าสู่ระบบแล้ว และอีเว้นต์เปิดให้ลงทะเบียน (precondition)

## Requirements
- FR-REG-01 ระบบต้องให้ผู้ใช้เลือกอีเว้นต์ และตรวจสอบจำนวนที่ว่างของอีเว้นต์นั้น          <- UC-04 main flow ขั้น 1-2
- FR-REG-02 เมื่อผู้ใช้ยืนยันการลงทะเบียน ระบบต้องบันทึกข้อมูลผู้ใช้เป็นผู้ลงทะเบียน
  และแสดงผลการลงทะเบียนสำเร็จ                                                     <- UC-04 main flow ขั้น 3-5
- FR-REG-03 หากจำนวนที่นั่งเหลือไม่เกินค่าที่กำหนด ([N] ที่นั่ง หรือ [P]% ของความจุ) ระบบต้องแจ้งจำนวนที่เหลือให้ผู้ใช้ทราบ <- UC-04 alternative flow
- FR-REG-04 หากจำนวนผู้เข้าร่วมเต็ม ระบบต้องไม่อนุญาตให้ลงทะเบียน และต้องแจ้งว่าที่นั่งเต็ม รวมถึงกรณีมีผู้ใช้หลายคนยืนยันที่นั่งสุดท้ายพร้อมกัน ระบบต้องให้ลงทะเบียนสำเร็จเพียงคนเดียวและปฏิเสธผู้ใช้อื่น <- UC-04 exception flow
- FR-REG-05 ระบบต้องไม่อนุญาตให้ผู้ใช้ลงทะเบียนซ้ำในอีเว้นต์เดียวกัน หากมีรายการลงทะเบียนเดิมที่ยังไม่ยกเลิก <- UC-04 NFR / acceptance criteria

## Quality Requirements
- NFR-SEC-01 ระบบต้องจำกัดการเข้าถึงข้อมูลผู้ลงทะเบียนเฉพาะผู้ใช้ที่เกี่ยวข้องและผู้จัดงาน; ทีมยืนยันว่าไม่มีมาตรการเพิ่มเติมนอกเหนือจากการจำกัดสิทธิ์นี้ (Q-03)
- NFR-DAT-01 ข้อมูลที่บันทึกต้องถูกต้องตรงกับที่ผู้ใช้ยืนยัน

## Acceptance Criteria
- [ ] AC-REG-01 (FR-REG-02)
      Given ผู้ใช้เข้าสู่ระบบแล้ว และอีเว้นต์เปิดให้ลงทะเบียนและมีที่ว่าง
      When  ผู้ใช้ยืนยันการลงทะเบียน
      Then  บันทึกสำเร็จ ผู้ใช้เป็นผู้ลงทะเบียนของอีเว้นต์ และแสดงผลลงทะเบียนสำเร็จ
- [ ] AC-REG-02 (FR-REG-02, NFR-DAT-01)
      Given ผู้ใช้ลงทะเบียนสำเร็จ
      When  ตรวจสอบข้อมูลที่บันทึก
      Then  ข้อมูลผู้ลงทะเบียนตรงกับข้อมูลที่ผู้ใช้ยืนยัน
- [ ] AC-REG-03 (FR-REG-03)
      Given อีเว้นต์เหลือที่นั่งไม่เกินค่าที่กำหนด ([N] ที่นั่ง หรือ [P]% ของความจุ)
      When  ผู้ใช้ตรวจสอบจำนวนที่ว่าง
      Then  ระบบแจ้งจำนวนที่นั่งที่เหลือ
- [ ] AC-REG-04 (FR-REG-05)
      Given ผู้ใช้มีรายการลงทะเบียนอีเว้นต์นี้ที่ยังไม่ยกเลิก
      When  ลงทะเบียนอีเว้นต์เดิมอีกครั้ง
      Then  ระบบไม่อนุญาต และไม่เกิดรายการลงทะเบียนซ้ำ
- [ ] AC-REG-05 (FR-REG-04)
      Given จำนวนผู้ลงทะเบียนของอีเว้นต์เต็มแล้ว
      When  ผู้ใช้พยายามลงทะเบียน
      Then  ระบบไม่อนุญาตให้ลงทะเบียน ไม่เกิดรายการลงทะเบียน และแจ้งว่าที่นั่งเต็ม
      Given ผู้ใช้หลายคนยืนยันการลงทะเบียนที่นั่งสุดท้ายพร้อมกัน
      When  ระบบประมวลผลการลงทะเบียน
      Then  มีผู้ลงทะเบียนสำเร็จเพียงคนเดียว ผู้ใช้อื่นถูกปฏิเสธ ไม่เกิดรายการลงทะเบียนเกินจำนวนที่นั่ง และแจ้งว่าที่นั่งเต็ม

## Assumptions & Open Questions
- ASM-01 จำนวนที่นั่งของอีเว้นต์ถูกกำหนดไว้แล้วในข้อมูลอีเว้นต์ และระบบอ่านจากข้อมูลนั้น
- ASM-02 "ลงทะเบียนซ้ำ" หมายถึงผู้ใช้คนเดียวกันในอีเว้นต์เดียวกัน
- ASM-03 กรณีผู้ใช้หลายคนยืนยันที่นั่งสุดท้ายพร้อมกัน ระบบให้ลงทะเบียนสำเร็จเพียงคนเดียว ปฏิเสธผู้ใช้อื่น และแจ้งว่าที่นั่งเต็ม
- ASM-04 การเข้าถึงข้อมูลผู้ลงทะเบียนอนุญาตเฉพาะผู้ใช้ที่เกี่ยวข้องและผู้จัดงาน
- ASM-05 รายการลงทะเบียนที่มีสถานะ "ยกเลิก" ไม่ถือเป็นรายการลงทะเบียนซ้ำ ผู้ใช้จึงลงทะเบียนอีเว้นต์เดิมใหม่ได้
- Q-01 ค่าเกณฑ์ "ที่นั่งเหลือน้อย" ถูกกำหนดเป็น N = 5 ที่นั่งที่เหลือ โดยเมื่อจำนวนที่ว่าง <= 5 ระบบจะแจ้งข้อความ "เหลือที่นั่งไม่เกิน 5 ที่นั่ง" และยังคงทดสอบ FR-REG-03 และ AC-REG-03 ได้ตามเงื่อนไขจริง
- Q-02 [ปิดแล้ว] บันทึก `user_id`, `event_id` และข้อมูลยืนยันของผู้ใช้ (`confirmation_snapshot`) โดยข้อมูลยืนยันต้องตรงกับที่ผู้ใช้ยืนยัน
- Q-03 [ปิดแล้ว] ไม่มีมาตรการเพิ่มเติมนอกเหนือจากการจำกัดสิทธิ์ตาม NFR-SEC-01 และ ASM-04
- Q-04 ผลการลงทะเบียนสำเร็จต้องแสดงข้อมูลใดบ้าง? (ต้องถามทีมเองหรือผู้จัดงาน)
- Q-05 [ปิดแล้ว] กลุ่มนักศึกษาและผู้ชมมีสิทธิ์ลงทะเบียนเข้าชมเหมือนกัน และเรียกรวมว่า "ผู้เข้าชม"; การลงทะเบียนแข่งขันดนตรีแยกจากการลงทะเบียนเข้าชมและอยู่นอกขอบเขตฟีเจอร์นี้
